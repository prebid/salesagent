# Known-failing storyboard-conformance checks — GENUINE production gaps only.
#
# One test id per line, matching a tests/storyboard/test_storyboard_conformance.py
# parametrized test keyed on (protocol, track, storyboard_id, step_id) from the real
# @adcp/sdk storyboard runner's measured output. Loaded by tests/storyboard/conftest.py
# to xfail(strict=False) exactly these test ids.
#
# WHAT THIS FILE ACTUALLY ENFORCES (three distinct signals, only two of which bite):
#   - REGRESSION — a failing check that is NOT listed here fails CI. This is the
#     signal the job exists for.
#   - DE-COLLECTION — a listed entry that resolves to no collected check fails CI
#     via ledger/fitness::stale_entries, computed in-session by
#     test_storyboard_conformance.pytest_generate_tests. This is what catches an
#     entry that stopped being graded (a closed capability gate, a rename).
#   - GRADUATION — a listed entry that IS collected and now PASSES does NOT fail
#     CI. The marker is strict=False by deliberate design (conftest.py:31-36:
#     an environment-dependent xpass must not redden the job), so it XPASSes
#     silently; pytest.ini sets no xfail_strict and the storyboard tox env adds
#     no flag. Graduation is handled by updating this file and its lock test
#     together — the same discipline as the e2e_rest ledger
#     (tests/bdd/conftest.py:39, also non-strict). If graduation should redden,
#     that needs an xpass assertion, not a comment here.
#
# The runner grades the agent once per PROTOCOL (mcp, a2a), so every entry carries
# its protocol as the first id segment. The two halves are independent ledgers in
# one file: an MCP-only fix graduates the mcp:: entry and leaves any a2a:: twin,
# which is exactly the drift this axis exists to expose. See the a2a section for
# why that half currently holds a single not-measured entry rather than per-check
# twins.
#
# Locked by tests/unit/test_storyboard_ledger_state.py — keep that test in sync.
#
# Runner-reported SKIPS (missing_test_controller, missing_tool, prerequisite_failed)
# are NOT ledgered here — they map to a native pytest.skip() in the test module
# instead (the conformance job's Core Invariant). Only genuine check FAILURES belong in this file.
#
# comply_test_controller/pagination-integrity is the sole PERMANENT won't-fix
# family (missing_test_controller — no test controller wired for these checks).
# RFC 9421 signing entries, when ledgered, are regular shrinking genuine-gap
# entries tied to #1291 (RFC 9421 message signing epic) — NOT permanent.
#
